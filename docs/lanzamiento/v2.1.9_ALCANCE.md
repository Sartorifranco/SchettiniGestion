# SCHPOS v2.1.9 — Alcance de lanzamiento

Documento de referencia para acordar con el socio **qué sale ahora** y qué queda para después.

**Fecha de corte:** 17 de julio de 2026  
**Rama:** `main`  
**Versión en ejecutable:** `2.1.9.0`

---

## Resumen ejecutivo (para el socio)

SCHPOS v2.1.9 es un **POS + gestión comercial** listo para operar ventas, stock, clientes, caja, facturación AFIP (con configuración), promociones y estadísticas. El instalador permite desplegar en PC de cliente con LocalDB. El licenciamiento se gestiona con AdminLicencias / claves Base64.

**Decisión de lanzamiento:** salir con esto **sin esperar** a Compras completas ni al módulo de Informes ampliado (ese trabajo está en sprints separados, ver `docs/avances/`).

## Fuera de alcance del lanzamiento v2.1.9

Queda explícitamente **fuera** de lo que se vende/entrega hoy:

1. Módulo Compras operativo de punta a punta (OC → recepción → factura)
2. Informes ampliados (valorización stock, comisiones, faltantes pedidos, etc.)
3. Cuentas corrientes proveedor como producto terminado
4. Activación de licencia 100 % online obligatoria (API existe, no es flujo único del cliente)

Estos ítems están en la hoja de ruta de `docs/avances/REGISTRO_SPRINTS.md`.

## Cómo generar el build de lanzamiento

```powershell
git checkout main
git pull origin main
# Compilar Release en Visual Studio o:
.\Instalador\build-release.ps1 -BuildInstaller
```

Usar **solo** `main` o el tag/commit `29d61a3` para builds que se entregan al socio. No mezclar con ramas `cursor/sprint*`.
