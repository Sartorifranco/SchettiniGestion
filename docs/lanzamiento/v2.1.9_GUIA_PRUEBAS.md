# Guía de pruebas — SCHPOS v2.1.9 (lanzamiento)

Checklist paso a paso para validar **la versión que sale al mercado**.  
No incluye funciones de sprints posteriores (Compras/Informes en menú).

**Pre-requisitos:** Windows 10/11, .NET 4.7.2+, SQL LocalDB, licencia válida con módulos Lite + los extras que quieras probar.

---

## 0. Instalación limpia

| Paso | Acción | Resultado esperado |
|------|--------|-------------------|
| 0.1 | Ejecutar `SCHPOS-Setup-2.1.9.exe` como administrador | Instalación sin errores |
| 0.2 | Verificar LocalDB: `sqllocaldb info MSSQLLocalDB` | Instancia existe |
| 0.3 | Abrir SCHPOS | Pantalla activación o login |
| 0.4 | Activar licencia (pegar clave o `licencia.key`) | Pasa a login |
| 0.5 | Login `admin` / contraseña bootstrap | Entra al menú principal |
| 0.6 | Cambiar contraseña en Usuarios | Guarda correctamente |

- Informes de comisiones, valorización stock, faltantes pedidos (sprint futuro)

Para eso usar la rama de avances y `docs/avances/GUIA_PRUEBAS_AVANCES.md`.
